# WakeStake
u snooze u lose

you stake money on waking up. set an alarm, lock a stake, scan the QR code in your bathroom before the alarm and the stake rolls over to tomorrow. oversleep and your friend group slashes it to a cause they voted on, and the swap into the charity's token runs on Uniswap.

the novel bit is privacy with a time lock: your alarm time, your stake and your identity never appear on-chain. the stake is a private commitment, and both "I woke up" and "they didn't" are zk proofs checked against a time window. waking needs a secret only you have (the QR code), so nobody can wake for you. slashing needs no secret but only works after the alarm has passed, so the group can punish you but never rob you. groups are ENSv2 names: `<group>.wakestake.eth`, members are subnames, and admin is whoever owns `admin.<group>.wakestake.eth`.

# how it works
1. **stake**: deposit an ERC20 into `WakeStake` as a private note (Poseidon commitment in a LeanIMT). your alarm time and a donation address are hidden inside. only you know `secret`, your friend group knows the rest.
2. **wake**: before the alarm you prove in zk that you know `secret`, and the stake rolls over to tomorrow's alarm (`wake()`). nothing about your alarm is revealed on-chain.
3. **oversleep**: after the alarm anyone in your group can prove you didn't wake up and slash the stake to the committed donation address (`withdraw()` with `lose = true`). the contract emits `YouLose` and the telegram bot shames you.
   - **cash out**: before the alarm the same proof lets only you (you know `secret`) take the stake back to any address (`withdraw()` with `lose = false`), no fee. yes, you can chicken out at 5am.
4. **friend groups**: the donation address is your group's `DonationGroup` contract. when a stake is lost, WakeStake asks the group where the money goes (`donationAddress()`). members vote on that and on the minimum stake. the group is an ENSv2 name, and every member is a subname.
5. **charity swap**: a group's donation address can be a `DonationRouter`, which swaps the slashed tokens on Uniswap into the token the charity wants.

# where the code is
## core (zk)
- [circuits/wakestake/src/main.nr](circuits/wakestake/src/main.nr): wake / withdraw circuit. [circuits/stake_ownership/src/main.nr](circuits/stake_ownership/src/main.nr): "I own an unspent stake of at least the minimum, donating to this group" without revealing which stake. [circuits/common/src/lib.nr](circuits/common/src/lib.nr): shared hashing.
- [contracts/WakeStake.sol](contracts/WakeStake.sol): `stake()`, `wake()`, `withdraw()`, and `getLoserDonationAddress()` which asks a group contract where a lost stake goes.
- `contracts/WakeStakeVerifier.sol` and `contracts/StakeOwnershipVerifier.sol` are generated by `pnpm build:verifier`.

## ENS v2 (Sepolia beta), prize: Best Use of ENSv2
- [contracts/DonationGroupFactory.sol](contracts/DonationGroupFactory.sol): `createDonationGroup()` deploys the group its own ENSv2 registry (a `UserRegistry` proxy via ENS's `VerifiableFactory`), registers `<group>.wakestake.eth` pointing at it, and hands `admin.<group>.wakestake.eth` to the creator. the factory is the only account with `ROLE_REGISTRAR` on the `wakestake.eth` registry, so only factory-made groups get a name.
- [contracts/DonationGroup.sol](contracts/DonationGroup.sol): `admin()` is whoever owns `admin.<group>.wakestake.eth`, so transferring the name transfers admin. `registerName()` gives a member who proves the minimum stake their own `<name>.<group>.wakestake.eth`. the group holds only `ROLE_REGISTRAR | ROLE_RENEW | ROLE_SET_PARENT` on its registry, so names it hands out can never be taken back. votes belong to names and follow transfers.
- [ignition/modules/WakeStake.ts](ignition/modules/WakeStake.ts) deploys the `wakestake.eth` registry and `admin.wakestake.eth`. [scripts/registerEnsName.ts](scripts/registerEnsName.ts) registers `wakestake.eth`, [scripts/linkEnsRegistry.ts](scripts/linkEnsRegistry.ts) points it at our registry.
- tests run against ENS's real contracts: [test/DonationGroupFactory.ts](test/DonationGroupFactory.ts), [test/DonationGroup.ts](test/DonationGroup.ts). the ENS sources are the `lib/contracts-v2` submodule (pinned to the Sepolia beta tag), compiled through [contracts/ens/EnsV2.sol](contracts/ens/EnsV2.sol).

## Uniswap v3 (Sepolia), prize: Best Uniswap Stack Contribution
- [contracts/DonationRouter.sol](contracts/DonationRouter.sol): `donate()` swaps a slashed stake into the charity's token through SwapRouter02's `exactInputSingle`, with the charity as the swap recipient.
- [src/uniswap.ts](src/uniswap.ts): QuoterV2 quotes and demo pool creation. [scripts/setup-donation-router.ts](scripts/setup-donation-router.ts) deploys a router and a funded pool on Sepolia.
- [app/src/services/chain/chainServices.ts](app/src/services/chain/chainServices.ts): the app quotes with QuoterV2 and calls `donate()` with a 1% slippage limit.
- [test/DonationRouter.ts](test/DonationRouter.ts): runs against the real Uniswap contracts on a Sepolia fork.

# deploy (sepolia)
store rpc url (`https://sepolia.infura.io/v3/<key>`), a funded deployer key and an [etherscan api key](https://etherscan.io/myapikey) in the encrypted keystore:
```sh
pnpm hardhat keystore set SEPOLIA_RPC_URL
pnpm hardhat keystore set SEPOLIA_PRIVATE_KEY
pnpm hardhat keystore set ETHERSCAN_API_KEY
```
regenerate the verifiers if a circuit changed, register `wakestake.eth` on the ENSv2 beta (once, safe to rerun), deploy and verify on etherscan, then point `wakestake.eth` at the deployed registry:
```sh
pnpm build:verifier
pnpm ens:register
pnpm hardhat ignition deploy ignition/modules/WakeStake.ts --network sepolia --parameters ignition/parameters.json --verify
pnpm ens:link
pnpm hardhat ignition deploy ignition/modules/TestToken.ts --network sepolia   # the staked demo token
pnpm hardhat run scripts/setup-donation-router.ts --network sepolia            # charity router + uniswap pool
```
addresses end up in `ignition/deployments/chain-11155111`. rerun the same command to resume a failed deploy.
if only verification failed, retry it with `pnpm hardhat ignition verify chain-11155111`.

`ignition/parameters.json` sets the contract `admin`, `feePayoutAddress` and `feePercentage`. anything left out defaults to the deployer and 5%.
the deployer registers `admin.wakestake.eth` to `admin`, and whoever owns that name is the only account that can change the fee payout address (same as `admin.<group>.wakestake.eth` for a donation group). transfer the name to hand over admin, with the registry's `unsafeTransfer`: the deployer keeps root roles on the wakestake.eth registry, so ENS refuses `safeTransferFrom` there.
after changing the circuit or contracts, redeploy with `--reset` (or a new `--deployment-id`), otherwise ignition refuses because the old deployment doesn't match.
